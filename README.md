## Upload options

### GitHub Pages

1. Create or recover access to the website repository.
2. Upload the contents of this folder to the repository root.
3. In repository Settings → Pages, publish from the main branch/root.
4. Keep `CNAME` only when the site should use `www.topchainfresh.com`.
5. Point the Squarespace-managed DNS records to the hosting provider.

### Netlify

Drag the entire folder or ZIP into Netlify Drop, then connect the custom domain in Netlify and update DNS in Squarespace.

### Cloudflare Pages

Connect a Git repository or upload the static assets through the supported Pages workflow. No build command is required; the output directory is the project root.

### Standard web hosting

Upload all files and folders to the public web root, usually `public_html`, `www`, or `htdocs`.

## Before public launch

1. Replace or confirm phone, email, business address, legal name, and social links.
2. Connect the contact form to Formspree, HubSpot, Salesforce, or a custom backend. The supplied static form currently opens the visitor’s email application.
3. Confirm claims such as “40+ years” and any future performance statistics.
4. Select an official trade dataset/year before calling the product categories a formal ranked “top 10.”
5. Review every image license and attribution requirement in `PHOTO_CREDITS.md`.
6. Add Privacy Policy, Terms, Cookie Notice, and Accessibility Statement appropriate to the company and jurisdictions served.
7. Optimize or self-host external photographs for production reliability and performance.

## Editing

- Global styling: `assets/css/styles.css`
- Mobile navigation, product filters, contact behavior: `assets/js/main.js`
- Page content: edit each `.html` file directly
